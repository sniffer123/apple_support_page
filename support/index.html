常见问题

没有 AI API Key 可以使用 LightAssist 吗？

可以。手工新增、编辑、完成、删除和查看日程，以及本地提醒，都不依赖 AI API Key。

AI 整理会发送哪些内容？

只有在你主动使用 AI 整理并明确同意后，当前文字和你选择的图片才会发送给你配置的第三方 AI 服务。原始录音不会发送给日程解析模型。

日程保存在哪里？

日程、草稿、设置和所选图片保存在设备中。LightAssist 开发者不运营用于保存这些日程数据的服务器。

如何删除数据或撤回 AI 数据发送同意？

打开 LightAssist 的“设置 → 数据与隐私”，你可以撤回第三方 AI 数据发送同意，或清除事项、草稿、附件、AI 配置和 API Key。

为什么语音识别或通知不能使用？

请在 iPhone 系统设置中检查 LightAssist 的麦克风、语音识别和通知权限。语音识别还要求设备端中文模型可用。

Frequently asked questions

Can I use LightAssist without an AI API key?

Yes. Creating, editing, completing, deleting, and viewing schedules manually, as well as local reminders, do not require an AI API key.

What is sent when I use AI organizing?

Only after you initiate AI organizing and explicitly consent are the current text and selected images sent to the third-party AI service you configured. Raw audio is not sent to the schedule parsing model.

How do I delete data or withdraw consent?

In LightAssist, open Settings → Data & Privacy to withdraw consent for third-party AI transfers or clear schedules, drafts, attachments, AI configuration, and API keys.
